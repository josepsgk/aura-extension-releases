# AURA — extensión para Chrome

Descarga e instalación de **AURA**, la extensión para exportar personajes y chats de JanitorAI (tarjetas PNG/JSON, TXT, lorebooks y scripts).

Este repositorio solo contiene las versiones para descargar.

## Descargar

**[Descargar la última versión (ZIP)](https://github.com/josepsgk/aura-extension-releases/releases/latest/download/aura-extension-chrome.zip)**

Versiones anteriores y notas de cada versión: [Releases](https://github.com/josepsgk/aura-extension-releases/releases).

## Instalar en Chrome

1. Descarga el ZIP y **descomprímelo** en una carpeta que no vayas a borrar (Chrome carga la extensión desde ahí).
2. Abre `chrome://extensions`.
3. Activa **Modo de desarrollador** (arriba a la derecha).
4. Pulsa **Cargar descomprimida** y elige la carpeta descomprimida (la que contiene `manifest.json`).
5. Recarga las pestañas de JanitorAI que tuvieras abiertas.

## Actualizar

Descarga el ZIP nuevo, descomprímelo **en la misma carpeta** (sustituyendo los ficheros) y pulsa el botón de recargar de AURA en `chrome://extensions`.

La extensión no se actualiza sola: está instalada en modo desarrollador, fuera de la Chrome Web Store.
